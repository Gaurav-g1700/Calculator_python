# Cyberpunk Desktop Python Edition

A Python desktop version of the Cyberpunk Desktop project.

## Install

Open PowerShell in this folder and run:

```powershell
python -m pip install -r requirements.txt
```

## Run

```powershell
python main.py
```

The app uses Tkinter for the interface, Pillow for the animated cyberpunk background, and pygame for MP3, WAV, OGG, FLAC, and M4A playback. The selected music folder, notes, and volume are saved in your user profile.

If the music folder does not exist on another computer, the app still opens normally; the user can choose another folder.
